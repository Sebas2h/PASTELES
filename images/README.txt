IMAGENES DE LA PAGINA DE INICIO - DULCE NARANJA
================================================

Esta carpeta debe quedar en la RAIZ del proyecto:
AplicacionPasteles/images/

La portada busca automáticamente estos nombres:

  hero.jpg      -> imagen principal grande
  panel1.jpg    -> panel 1: Nuestra historia
  panel2.jpg    -> panel 2: Hecho con cariño
  panel3.jpg    -> panel 3: Sabores y diseños
  panel4.jpg    -> panel 4: Para cada ocasión
  panel5.jpg    -> panel 5: Cierre / experiencia de marca

También puedes usar .jpeg, .png o .webp manteniendo el mismo nombre base,
por ejemplo: hero.webp o panel3.png.

Si todavía no colocas una imagen, la página mostrará un recuadro bonito de
referencia indicando qué archivo corresponde a cada espacio.

Recomendación:
- hero: imagen horizontal o vertical grande, mínimo 1200 px de ancho.
- panel1 a panel5: imágenes de buena calidad, idealmente 1000 x 800 px o más.
- Evita archivos demasiado pesados para que la página cargue rápido.
